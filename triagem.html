Quem chega primeiro não é quem é atendido primeiro. Quem corre mais risco é.

Este é o sistema de acolhimento e classificação de risco da unidade. O paciente preenche a própria ficha, a enfermagem mede os sinais vitais e define a prioridade do atendimento.

Em emergência com risco imediato, procure a equipe no balcão ou ligue 192. Não espere pelo sistema.

Sistema de demonstração acadêmica · Dados tratados conforme a Lei 13.709/2018 (LGPD)

Manual do sistema

Veja como usar cada parte do sistema.

Paciente

  1. Clique em Sou paciente.
  2. Crie seu cadastro preenchendo seus dados.
  3. Aceite o termo de consentimento.
  4. Entre usando CPF e senha.
  5. Abra um atendimento, descreva seus sintomas e escolha sua dor.
  6. Envie a ficha para a triagem.
  7. Acompanhe seu histórico pelo painel.

Enfermeiro(a)

  1. Entre pela opção Sou enfermeiro(a).
  2. Veja a fila de pacientes.
  3. Clique em um paciente para abrir a ficha.
  4. Registre os sinais vitais.
  5. Escolha a classificação de risco.
  6. Faça as anotações necessárias.
  7. Salve e finalize o atendimento.

Técnico(a) em enfermagem

  1. Entre pela opção Sou técnico(a).
  2. Veja os pacientes que estão aguardando.
  3. Registre os sinais vitais.
  4. Os dados mais sensíveis aparecem protegidos.
  5. A classificação feita pelo técnico precisa ser confirmada pelo enfermeiro.
  6. O técnico não finaliza o atendimento.

Privacidade e LGPD

O sistema trabalha com dados pessoais e informações de saúde. Por isso, o acesso deve ser controlado.

  • O paciente aceita o consentimento.
  • Os dados são usados para a triagem.
  • Alguns dados aparecem protegidos para o técnico.
  • O paciente pode consultar seus dados.
  • O paciente pode exportar seus dados.
  • O paciente pode solicitar a exclusão dos dados.
Atenção: este projeto é uma demonstração acadêmica. Não utilize dados reais de pacientes.
